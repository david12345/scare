# Ala 13

Jogo de terror em primeira pessoa, em 3D, num único arquivo HTML (Three.js).

Abra `index.html` no navegador. Junte as 6 páginas do diário do Dr. Moura e encontre a saída antes que *ele* te encontre.

- **W A S D**: andar
- **Shift**: correr (faz barulho)
- **F**: lanterna
- **Mouse**: olhar
- **Esc**: pausar

No celular: arraste à esquerda para andar e à direita para olhar.
